After a succesful run, the directory tree will look like this:

```text
genomics/
├── negative_control_data/
├── fitted_error_model/  
├── tumor_data/
├── unfiltered_variant_calls/
└── filtered_variant_calls/
```

The final output is located in the ```filtered_variant_calls/``` directory.
